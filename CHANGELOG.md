# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-25

### Added
- Identity system: habits cast XP "votes" for identities with four levels (Novice 🥉, Consistent 🥈, Explorer 🥇, Master 💎).
- 30-day rolling consistency score per habit and overall, with streaks shown as a secondary metric.
- Never-Miss-Twice warnings on critical days.
- Freeze / rest days with a monthly allowance, available per habit or for a whole day.
- Daily Focus Identity that doubles XP.
- Adaptive difficulty: a one-click micro-habit appears after 3 consecutive misses.
- Burnout Guard for sustained heavy-habit load.
- Smart insights: weekday friction, habit correlations, identity balance and best weekday.
- GitHub-style heatmap (90 / 365 days), monthly Markdown report and an `identity-tracker` code block.
- Two-way daily-note frontmatter sync.
- English / Arabic interface with instant RTL switching.
- Optional auto-integration with the Habit Journey and Reading Journey plugins.
